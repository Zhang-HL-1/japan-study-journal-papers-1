# japan-study-journal-papers-1

This repository holds full-volume past-paper PDFs for japan-study-journal, so the main site can stay under GitHub Pages’ 1 GB limit. Files are the original bytes at `<school>/<sha256>.pdf`. This volume holds hokkaido, keio, kyushu, science-tokyo, sophia, tohoku, tus, and uec. Two PDFs that Sophia shares with Kyushu are stored only under `kyushu/`. The pilot page remains in `pilot/`. GitHub Pages serves this branch from `/`.
